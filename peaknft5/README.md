## 🚀 Overview
**PeakNFT** is a decentralized Web3 platform that allows users to mint, manage, and store digital assets securely using blockchain technology. Built on the **Internet Computer Protocol (ICP)** using **Motoko** for smart contract canisters and a responsive React frontend.

---

## ✨ Key Features

* **🎨 NFT Minting Engine:** Securely mint unique digital assets onto the blockchain with automated metadata management.
* **📦 Decentralized Storage:** Leverages decentralized storage containers for persistent and tamper-proof asset metadata.
* **🔐 Wallet Connectivity:** Seamless wallet integration for secure user authentication and transaction signing.
* **⚡ Canister Architecture:** Built using high-performance Motoko canisters deployed on the Internet Computer network.

---

## 🛠️ Tech Stack

* **Blockchain / Backend:** Internet Computer Protocol (ICP), Motoko (Smart Contracts)
* **Frontend:** React.js, JavaScript, HTML5, CSS3
* **Tools:** DFX CLI, Node.js, Git

---

## ⚙️ Quick Start & Deployment

To run and deploy the canisters locally using DFX:

```bash
# Navigate to project directory
cd peaknft5

# Install dependencies
npm install

# Start local DFX network
dfx start --background

# Wait for network to initialize
sleep 10

# Deploy canisters
dfx deploy

# Setup environment variables
node setup-env.js

# Start frontend development server
npm start
